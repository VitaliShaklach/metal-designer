# История версий

## v1.0.0 — 2026-10-07

Первый публичный выпуск на GitHub Pages.

**Конфигуратор мангала и печи** (`mangal/`)
- Режимы: мангал, печь под казан, печь + мангал.
- 3D-модель: клик по детали — показать только её; имя детали под курсором; двойной клик — вся модель.
- Размеры на модели — каждая отдельной галочкой, сворачиваемые группы; единицы **мм** (по умолчанию) или **см**.
- Вкладки: размеры, раскрой и масса, DXF для лазера (по детали и все ZIP), что купить, заметки.
- Справка «Управление»: мышь, телефон, горячие клавиши (`F`, `Esc`, `1`–`3`, `D`, `X`, `U`, `?`).
- «Поделиться видом» — ссылка с камерой, деталью, размерами и галочками.
- Телефон: панель настроек — выдвижная шторка.
- Колосниковая решётка жаровни на уголках, задвижки поддува, съёмная перегородка, откручиваемые ножки на колёсах, крыша с крепежом.

**Сайт**
