# Пометки Виталия → правка фигуры

Виталий рисует красным на снимках с калькой, Claude переносит пометки на модель. Так «Доберман 8» сделан из 7-го (v0.6.4).

1. **Снимки.** Скопировать `shot.js` в `art/_mk.js`, а `art/index.html` — в `art/_mk.html` с `<script src="_mk.js">` в конце. Снимать headless Chrome 1800×1800, адрес `_mk.html#f=<id>&trace&og&mk=<имя>[&c=x,y,z&r=радиус&d=направление]`. Параметры камеры (`--dump-dom`, `body[data-out]`) сохранить рядом со снимком (`_камеры/*.json`). Папка для Виталия — `C:\dev\<изделие>-пометки\`, вне репо.
2. **Пометки → 3D.** `node map.js <снимок>` — красные куски (сравнение с исходным снимком), лучи из камеры на модель: точки, грани, ближайшие рёбра. `crop.js` — увеличить кусок, чтобы рассмотреть.
3. **Правка.** Пример — `round1.js`: перестановка граней, точки на линии (закреплены, затем спроецированы на поверхность эталона), слияние, новый шов, затем `solve` из `../clean.js` (плоские плиты, остальные точки как можно ближе к прежним). Итог — `.json` для `fromjson.js` с `ref` и `frame`.
4. **Проверка.** `check.js`, `smoke.js`, снимки «до/после» теми же камерами.

`base.js` берёт Доберман 7 из `models-poly.js` и переводит в координаты страницы (габарит 291×600×395). Для другой фигуры поменяйте id и габарит.
