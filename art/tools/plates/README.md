# Новое изделие из Meshy: процесс

Как из модели Meshy получить фигуру для сайта: плоские плиты, раскрой, DXF и PDF, плюс калька эталона в редакторе. Отработано на «Доберман 7».

## Кто что делает

| Шаг | Кто | Что |
|---|---|---|
| 1 | Виталий | В Meshy делает модель «Изображение → 3D» **с текстурой** в гранёном стиле (Geometric): плиты и швы должны быть нарисованы на текстуре |
| 2 | Виталий | Проверяет в просмотрщике Meshy и скачивает **OBJ** (zip: .obj + .mtl + .png). Присылает путь к zip и название изделия |
| 3 | Claude | `make.js` — плиты, фигура на сайте, калька; показывает сверку «эталон \| наша» и цифры |
| 4 | Виталий | Редактор: «Править фигуру» + «Калька». Красное — убрать шов, жёлтое — провести. Затем «Сохранить» (.json) и прислать файл |
| 5 | Claude | `fromjson.js` — правленая фигура становится встроенной (например, «Доберман 8»); тесты, снимки, коммит. Пуш — по команде Виталия |

## Какая модель подходит

- **Швы нарисованы на текстуре.** Светлыми линиями или ржавыми полосами сварки. Без нарисованных швов плиты не найти.
- **Симметрия лево–право.** Строится правая половина, левая — её зеркало.
- **Настенная.** Спина на стене (z = 0). У стены швы не ищутся, открытый край там допустим.
- **Глаза и прорези.** Тёмные пятна на текстуре станут прорезями с подложкой.

Что-то не так? Пороги подкручиваются параметрами `plates.js` (`seam`, `ang`, `mm`…) — их можно передать в `make.js`. Несимметричную или отдельно стоящую фигуру конвейер пока не умеет.

## Команды

```bash
# 3. модель → фигура на сайте (около минуты)
node art/tools/plates/make.js bull1 "C:/…/model.obj" "Бык 1"   # [текстура.png] [seam=185 ang=4 …]

# 5. правка из редактора → встроенная фигура (швы, проведённые руками, сохраняются)
node art/tools/plates/fromjson.js doberman8 "C:/…/Доберман 7.json" "Доберман 8"

# проверка
node art/tools/smoke.js
node art/tools/plates/check.js bull1
node art/tools/plates/creases.js bull1   # швы на изломах эталона: доля в 3 мм (Доберман 7: 73%), худшие рёбра
node art/tools/plates/plates.js dump=1   # то же по стадиям конвейера
```

`make.js` по шагам, если нужно по отдельности:

1. `prep.js` — OBJ + PNG → `out/mesh.json`, `out/tex.json`.
2. `plates.js` — плиты → `out/plates.json`, картинки `out/pl_*.png`.
3. `export.js <id>` — запись в `art/js/models-poly.js`.
4. `tracing.js <id>` — калька `art/js/trace-<id>.js`.
5. Регистрация в `figures.js` и `index.html`.
6. `check.js` — проверка фигуры.
7. `ref.js` — сверка `out/cmp_*.png`.

Исходник модели копируется в `src/` и в git не идёт. `src/` и `out/` в `.gitignore`.
