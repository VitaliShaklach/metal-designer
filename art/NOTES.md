# Искусство — заметки и решения

Записано по переписке с Виталием, 2026-10-20.

## Термины
- **КОМПАС-3D** — российская CAD-программа (АСКОН), аналог Inventor и SolidWorks. Режим «Листовое тело» моделирует детали из листа; скрин быка из «Загрузок» сделан в нём.
- **OBJ** — простой старый формат. Грани могут быть треугольниками, четырёхугольниками и многоугольниками, поэтому удобен для гранёных фигур. Открывается в Blender, КОМПАСе, 3ds Max.
- **STL** — формат для 3D-печати, внутри только треугольники. Сохраняет любая CAD-программа.
- **GLB** — современный формат для веба и игр: форма плюс цвета и текстуры. Его чаще всего выдают сервисы «фото → 3D» (Meshy, Tripo).
- Раздел `art/` открывает все три формата.

## Что пишем сами, что берём готовое
Это узкий инструмент: гранёная фигура из листа → детали для производства. КОМПАС, Blender и Meshy не повторяем.

**Берём готовое:**
- КОМПАС и Blender — лепить модель, если захочется;
- Meshy и Tripo — модель из фото;
- Three.js — 3D в браузере.

**Пишем сами:**
- открыть OBJ, STL и GLB;
- упростить модель до нужного числа граней;
- растянуть по высоте, ширине и глубине с пересчётом;
- разбить на детали: номера, масса, длина реза, длина швов;
- край детали под толщину листа, раскладка на лист, DXF, PDF со сборкой;
- простой редактор (этап 2): тянуть точки, симметрия, разрезать и выдавить грань.

## Meshy по API — позже
- **Как работает:** отправляем фото (ссылкой или файлом) → получаем номер задачи → спрашиваем «готово?» → получаем ссылки на GLB или OBJ.
- **Число граней:** вроде бы его можно задать в запросе, тогда модель сразу гранёная. Перед подключением сверить с документацией Meshy.
- **Ключ API платный**, тратит кредиты. На GitHub Pages ключ хранить нельзя.
- **Нужен посредник:** маленький сервер, например Cloudflare Worker (бесплатный). Ключ лежит у него. Защита — кнопка только для Виталия или лимит в день.
- **Цены и доступность API** на бесплатном тарифе проверить на сайте Meshy. Tripo сравнить.
- **Аккаунт и ключ** заводит Виталий сам; Claude ключи не трогает.
- **Когда:** после этапов 1–2, по команде Виталия.
