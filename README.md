# Metal Designer

3D-конфигураторы изделий из металла прямо в браузере: модель, размеры для сварщика, раскрой и масса, файлы DXF для лазерной резки.

**Сайт:** https://vitalishaklach.github.io/metal-designer/

## Проекты

| Папка | Что это |
|---|---|
| [`mangal/`](mangal/) | Мангал, печь под казан или оба вместе: колосник, задвижки поддува, съёмные ножки на колёсах, крыша от дождя |

Печи и металлоконструкции — в работе.

## Что умеет конфигуратор мангала

- 3D-модель (Three.js): вращать, приближать, клик по детали — показать только её.
- Размеры на модели — каждая отдельной галочкой; единицы — **мм** или **см** (переключатель в шапке).
- Раскрой и масса металла, список покупок.
- DXF для лазера: каждая листовая деталь отдельным файлом (контур и отверстия — слой `CUT`, гибы — `BEND`, в мм), все сразу — ZIP.
- «Поделиться видом» — ссылка на ту же камеру, деталь, размеры и галочки.

## Как устроено

Без сборки: обычные `<script>` в одной области видимости, Three.js r128 с CDN.

```
mangal/
  index.html        страница
  css/style.css
  js/params.js      параметры и размеры модели (внутри — в см; на экран — через u(): мм или см)
  js/parts.js       справочник элементов и деталей
  js/model.js       3D-модель
  js/dims.js        размеры на модели и их список
  js/cut.js         раскрой, масса, металл
  js/dxf.js         DXF и ZIP
  js/ui.js          интерфейс
  tools/            проверки (Node, headless-браузер)
```

## Проверка

```
node mangal/tools/smoke.js      # 0 строк без «ok» — всё хорошо
node mangal/tools/labels.js grill mm   # все подписи размеров текстом
```

Тот же дымовой тест запускается на GitHub при каждом push (`.github/workflows/check.yml`).

Ссылка с видом без интерфейса (для снимков): добавьте к ссылке `&shot=1`.

После правок JS/CSS поднимите версию `?v=…` (сейчас 1.0.1; при выпуске — та же, что в CHANGELOG и подвале) в `mangal/index.html`, чтобы браузеры не брали старые файлы из кэша.
