**Цель Виталия:** текст, эскиз в приложении или фото эскиза → 3D-модель с размерами → чертежи для производства как PDF МК-16 (Inventor; рендеры листов образца — `C:\dev\mk16`, вне репо).

**Состояние на 28.10.2026:** v0.3.1 запушен (6af2af6): чертежи А3 (общий вид, лист на сборку, детали), МК-16 целиком (308 деталей) и каждая сборка отдельно. Тест `node karkas/tools/smoke.js` сверяет с МК-16: 790/685/520/605, 41°/49°.

**Устройство:** `model.js` — M={nodes,members,groups,meta}, мм, Y вверх; стыки `resolveEnds` (2 одинаковые → скос; разные → толстая cap + тонкая butt; Т-узел → butt; 3+ → вертикальная cap; крестовой `crossJoint`), позиции «группа.поз», раскрой по 6 м, `memo()` — кэш. `tools/make-mk16.js` собирает сборки и всё изделие, сверяет со спецификацией PDF → `examples/mk16*.json` → `tools/make-examples.js`. Текст и фото пока через чат: Claude собирает model.json → вкладка «Модель (JSON)» → «Применить».

**Не сделано:** отверстия в трубах (`members[].holes`: Ø12 в столбах 4.1, Ø5/Ø9 в полосах); вложенные сборки (1.5СБ внутри 1СБ); выносные виды и разрезы; профнастил. Расхождения с PDF: 3СБ — у нас 1930×9 вместо 1930×7 + 2010×2; 2СБ — раскладка правой секции приблизительная. Потом — ИИ на сайте через сервер (Cloudflare Worker).
