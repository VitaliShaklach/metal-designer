Добавляю в модель мангала (`mangal/js/` params, parts, model, dims, cut, ui) новый элемент или деталь — в той же правке:
1. своя галочка показа в панели (и деталь в `PARTS` для списка «Показать → Деталь»);
2. размеры элемента — каждый отдельной галочкой в «Размеры на модели» (по умолчанию выключены), под своим заголовком `#…`;
3. строка в раскрое.

Элемент есть не во всех режимах (печь + мангал / мангал / печь) — указать режимы, чтобы он и его размеры не появлялись в чужом.

**Why:** Виталий попросил сделать это правилом (02.10.2026): иначе приходится отдельно просить размеры и галочки к каждой детали.
**How to apply:** задача «добавь X» не закончена, пока у X нет галочки, размеров и строки раскроя; проверять снимком с включёнными размерами. См. [[mangal-project-state]].
