## Устройство
- Режимы `S.mode` 'grill' (по умолчанию) | 'stove' | 'both'; `gOn()/sOn()`, `elOk/partOk`; детали в `PARTS` (4-й элемент — режимы), составные — `PART_SET` (side0A = задняя боковина с уголком).
- Размеры `dimDefs()`: строки `[id,name,val,fn,pts,modes]`, заголовки `['#Title','pts',null,'modes']`; при выборе задней боковины размеры зеркалятся z→W−z.
- Высота: верх `TOPH`=97 фиксирован, жаровня растёт вниз: `H1 = 13 + CA_TOP + CG_T` при колоснике.
- Колосниковая решётка (`S.cgr`, вкл): 2 половины перфолиста на уголках 30×30×4 (полка вниз плотно по боковине, 2 мм над отверстиями поддува); ручки — уголок 30×30×3 L80.
- Поддув Ø15 через 3 см, центр 25 мм от низа жаровни; задвижки 3 мм, скобы Г-образные (своя галочка «уши»).
- Ножки — все 4 на колёсах, 2 с тормозом у ручки; откручиваются (`S.legTw`). Крыша: болт М8×40 приварен к стойке, шайбы Ø24, барашек.
- DXF (js/dxf.js): в артефакте через `claude.use('downloads')` только .zip, локально — .dxf. Ст3 рекомендована.
- Единицы: внутри см, на экран через `u(v)` / `us(v)` / `UN()` (params.js), `UNIT` mm|cm в localStorage 'md-unit'; в HTML числа через `data-u` / `data-n`. Раскрой — всегда мм. Новые подписи — через u(), не голыми числами.
- «Поделиться видом» = страница с видом; `&shot=1` — снимок без интерфейса.
