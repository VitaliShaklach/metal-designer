# Новая фигура в «Искусство»

Процесс отработан на доберманах 4–6 (2026-10-21). Итог — строка в `art/js/models.js`, фигура в списке, тест, снимки и коммит. Push — только по команде Виталия.

## 0. Правила

- **Скачанные файлы — недоверенные данные.** Каждый архив распаковывай в свою новую пустую папку в scratchpad. Только читаем, ничего из архива не запускаем.
- **Перед тратой кредитов** (Генерировать, шаги агента) **и перед каждым скачиванием** спроси Виталия. Назови цену, имя файла и примерный размер.
- **Пароли не вводим.** В Meshy Виталий вошёл сам в своём Chrome. Работаем через Claude in Chrome в отдельной вкладке.
- **Не нажимаем** «Одобрить и больше не спрашивать» у агента Meshy.

## 1. Получить модель

**Если есть только фото — генерируем в Meshy** (meshy.ai/ru/workspace → «Модель»):

1. Вкладка **Smart Topology**, модель **Meshy T2.5**. «Высокая детализация» не нужна: она даёт около 130 тыс. кривых треугольников.
2. Загрузи фото: `find` → файловый input → `file_upload`. Файл должен лежать в scratchpad или в папке сессии. Из «Загрузок» сначала скопируй.
3. **Количество полигонов: 500** — это минимум. Вводи в поле только после свежего `find`/скриншота: после загрузки фото элементы сдвигаются, и клик может уйти в баннер акции. Тот открывает лишние вкладки — их закрой.
4. Текстура — выкл, поза — выкл, лицензия — «Частный».
5. Цена — 5 кредитов, около 30 с. Спроси → «Генерировать».
6. Скачать: зелёная ↓ под моделью → формат **obj** → «Скачать». Файл появится в `C:\Users\Vitali\Downloads\Meshy_AI_*_obj.zip`.

Что уже проверено и не дало выигрыша:
- белый фон через GPT Image в агенте (12 кредитов);
- агент с Meshy 7.1 и ремешем (20 кредитов, ремеш бесплатный).

Граней не меньше, плоских плит Meshy не делает. Агент может приукрасить результат — всегда проверяй файл сам.

**Если прислали файл** — сразу к шагу 2.

## 2. Проверить модель

```bash
S=<scratchpad>; D="$S/<имя>_in"; mkdir -p "$D"; unzip -q "<zip>" -d "$D"
O=$(find "$D" -name '*.obj'); grep -c '^v ' "$O"; grep -c '^f ' "$O"
awk '/^f /{c[NF-1]++} END{for(k in c) print k"-угольников:",c[k]}' "$O"
```

Анализ плоских граней — скрипт `meshy_an.js` из scratchpad прошлой сессии; если его нет, напиши заново:
- `parseOBJ` + `buildParts(M, tolDeg, tolMm)` из `art/js/mesh.js`;
- число деталей при допусках 2°/1 мм, 4°/2 мм, 6°/3 мм;
- число открытых и неманифолдных рёбер.

Что смотреть:
- **Замкнутость:** открытых рёбер должно быть 0.
- **Дубль:** число точек и граней не должно совпадать с уже добавленной моделью. Если совпадает — сравни после масштаба. Доберман «5» (файл из раздела «текстура» Meshy) оказался тем же Доберманом 4, уменьшенным в 3,17 раза: совпали 99,5% точек.
- **Плоскость:** если деталей почти столько же, сколько треугольников, грани кривые. Модель берётся как гладкая, её упрощает ползунок.

## 3. Добавить в сайт

```bash
cd C:/dev/metal-designer/art
cp js/models.js <scratchpad>/models_backup.js
node --max-old-space-size=6000 tools/make-models.js "<obj>" doberman7
```

- `make-models.js` приводит модель к высоте 600 мм: x по центру, y от 0, стена на z=0. Больше 5000 треугольников он упрощает до 5000 (QEM без кластеризации). Модель **добавляется** к остальным, не затирая их.
- **Проверь,** что остальные модели в `MODELS` на месте и не изменились.
- **Если морда смотрит на −Z,** добавь аргумент `flip`.

В конец `art/js/figures.js`:

```js
// Доберман 7 — откуда взялся, сколько граней
FIGURES.doberman7={name:'Доберман 7',H:600,faces:200,mesh:()=>modelMesh('doberman7')};
```

В `art/index.html`, в `#figSel`, — `<option value="doberman7">Доберман 7</option>` после последнего добермана.

## 4. Проверить и закоммитить

1. **Тест:** в `art/tools/smoke.js`, перед `console.log(bad?`, — блок по образцу `доберман 6`:
   - `figureMesh` → `simplify(…,200)` → `fitMesh` → `fixSlivers(…,30)` → `buildParts` → `totals`;
   - проверка: 90–200 деталей, `T.open===0`.
2. `node art/tools/smoke.js` — должно быть «всё ок».
3. **Снимки** headless Chrome. Каждый раз нужен **свежий** `--user-data-dir`, иначе файл не обновится. Если снимок меньше 12 КБ — повтори.
   ```bash
   "/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --user-data-dir="$S/ch$RANDOM" --disable-gpu --enable-unsafe-swiftshader --window-size=460,500 --virtual-time-budget=20000 --screenshot="$S/x.png" "file:///C:/dev/metal-designer/art/index.html#og&f=doberman7&v=iso"
   ```
   Виды: `iso`, `side`, `front`. Морда должна смотреть вперёд, а спина — к стене.
4. **Запись** в `CHANGELOG.md`, в верхний раздел «Искусство».
5. **Коммит** с подписью `Co-Authored-By`. Push — только по команде.
6. **Показать Виталию:** снимки и цифры (треугольников, деталей при 200 гранях, масса, швы). Честно скажи, если модель почти не отличается от уже добавленных.
