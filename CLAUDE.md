# Metal Designer — правила для Claude

Сайт-конфигуратор изделий из листового металла. Три раздела, без сборки: обычные `<script>` в одной области видимости, Three.js r128 с CDN.
- `mangal/` — мангал (1.x), `karkas/` — каркасы, `art/` — «Искусство»: фигуры из листа (развёртки, гибка, раскрой, DXF, чертежи, карты деталей).
- Проверки — `<раздел>/tools/smoke.js` (Node vm, без браузера), запускать из папки раздела: `cd art && node tools/smoke.js`.

## Правила
- Обращаться «Виталий». Пуш (`git push`) — только по команде «пушни». Коммиты локально — можно.
- Серьёзная правка (новая фича, меняется поведение/расчёт, несколько файлов) — сначала план и «да». Мелочь — сразу.
- Мангал и его PDF не трогать, пока не попросят.
- Рамка чертежа («в рамке») — только vashaklach@gmail.com.
- Meshy — спросить перед тратой кредитов. Пароли не вводить.

## После правок
1. Поднять версию раздела везде: все `?v=` в `<раздел>/index.html`, `v=` в js (у art — trace-скрипт в `ui.js`), `<span class="ver">`.
2. Запись в `CHANGELOG.md`: `## Искусство vX — дата` / `## Каркасы vX — …` / `## vX — …` (мангал).
3. Хук `.githooks/pre-commit` сам проверит п.1–2 и smoke задетых разделов. Включить один раз на клон: `git config core.hooksPath .githooks`. `--no-verify` — только со слова Виталия.
4. Правки в `art/` — пройти скил `art-verify` (картинки, превью, телефон/iPad).
5. Новое изделие в «Искусство» — скил `art-add-figure`. Бэклог — `art/BACKLOG.md`.
